# 为什么 4.3 m/s 几乎不被选用

结论：不是策略学坏了，是三个结构性原因叠加——刹车型号错了一个数量级、4.3 这一档没有转向权、4 worker 下起点覆盖减半。前两条已在 `speed_2018_pace_v6` 修复。

数据来源：`training-simtrace` 里最快的一圈（8.31s，2018 赛道，v4b 档位 1.6/2.0/2.9/4.3，127 步）。

## 观测事实

| 指标 | 数值 |
| --- | --- |
| 4.3 m/s 出现的步数 | 3 / 127 = **2.4%** |
| 直道（曲率 < 0.1）步数 | 16 步 |
| 直道上的速度选择 | 2.0 ×10、2.9 ×3、1.6 ×3，**4.3 零次** |
| 直道总长 / 最长一段 | 3.5m / 1.9m |
| 位移速度 ÷ 指令速度（p50） | **1.00** |

最后一行是关键：位移速度和指令速度相等，说明车在一个 65ms 控制步内就达到指令速度，仿真里的加减速接近瞬时。

## 原因一：刹车距离模型错了五倍

`_target_speed` 用 `v²/(2a) + 1m` 决定前视多远找弯，`a = 2.5~2.8 m/s²`。4.3 m/s 时前视 **4.3m**。

这条赛道最长直道 1.9m。也就是说，**每一个直道都落在下一个弯的“刹车窗口”里**，目标速度永远不会被允许升到 4.3，直道上只会给出 2.0~2.9 的目标。策略按目标开车，自然一次都不选 4.3。

实测减速能力约 15 m/s²（一帧到位），2.8 只有它的 1/5。

v6 的修改：`BRAKE_ACCEL = 12.0`，前视 `v²/24 + 0.6`，4.3 m/s 时降到 **1.37m**，直道终于能“看见”自己是直的。

## 原因二：4.3 这一档没有转向

旧网格里 4.3 只配了三个动作：`(-5, 4.3) (0, 4.3) (5, 4.3)`。

这条赛道 85% 的时间处在曲率 0.1 以上的弯里，需要 15° 以上转向。**想用 4.3 就必须放弃转向**，等于这一档只存在于“绝对直线”，而这条赛道没有绝对直线。

v6 改成 5 速度 × 5 转向的矩形网格（25 个动作），`(±30, 4.3)` 也存在，弯里想快就有对应的动作。

## 原因三：超速惩罚的形状

```python
speed_score = (0.25 + 1.5 * target_match) * exp(-((overspeed / 0.9) ** 2))
```

超目标 0.9 m/s 奖励掉到 37%。这个形状本身没问题，问题是它乘在一个**错误偏低的目标**上——目标说 2.0，选 4.3 就是“超速 2.3”，奖励几乎归零。策略学到的是“4.3 = 挨罚”，warm start 之后再也翻不了身。

目标速度修正后可以保留 0.9；如果实测发现它仍然压制探索，再放宽到 1.2。这是下一轮 A/B 的候选变量之一。

## 评估轨迹：4 worker 下起点只覆盖半条赛道

上游文档的硬性公式：

```
(num_episodes_between_training / DR_WORKERS) * DR_TRAIN_ROUND_ROBIN_ADVANCE_DIST = 1.0
```

2 worker 时 `10 × 0.1 = 1.0`，正确。4 worker 时变成 `5 × 0.1 = 0.5`——**一个迭代只有半条赛道被作为起点采样过**，另一半从来不是起点，车在那里更容易冲出去。

两种修法，二选一：

- **推荐**：`num_episodes_between_training` 20 → 40，ADVANCE 保持 0.1。每 worker 10 回合，覆盖补齐，同时每次参数更新的样本翻倍，缓解多头采样的方差。
- 备选：ADVANCE 0.1 → 0.2。只补覆盖，不解决方差。

## 最佳模型选择：配置项里没有“圈速”

`DR_TRAIN_BEST_MODEL_METRIC` 只接受两个值：

- `progress`：选评估完成率最高的，可能选到“稳但慢”的
- `reward`：选评估奖励最高的，跨奖励版本不可比

比赛要的是“完成率 100% 的圈里最快那一个”，这个配置项给不了。只能赛后手动选：

1. 读 `metrics/TrainingMetrics.json`
2. 筛 `phase=evaluation`、`episode_status=Lap complete`、`completion_percentage=100`
3. 取 `elapsed_time_in_milliseconds` 最小的一行
4. 用它对应的 checkpoint 号导出（`dr-download-model` 或控制台按 checkpoint 导出）

这一步应该写进复赛的最后 5 分钟流程，而不是指望“best”自动选对。
