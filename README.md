# DeepRacer 云端训练与 AI 协作实践

基于社区项目 [deepracer-for-cloud](https://github.com/aws-deepracer-community/deepracer-for-cloud) 的教学实践补充：奖励函数迭代、只读训练看板、本地日志同步与离线测试。这里不是完整训练平台，也不包含训练镜像或模型权重。

**新手入口：[懒人部署指南](docs/懒人部署指南.md)**（区分新机安装与旧机续训，命令逐块复制）。

域名访问方案：[阿里云 DNS + HTTPS + 登录保护](docs/域名与私有访问.md)。该文是待实施方案，不表示公网入口已经上线。

## 电脑、云服务器和 AI 分别做什么

| 角色 | 工作 |
| --- | --- |
| 云端 GPU 虚拟机 | 运行 Docker、仿真器、强化学习训练、MinIO 和看板后端 |
| 本地电脑 | 浏览看板与摄像头、通过 SSH 管理服务器、备份日志、保存代码 |
| AI / harness | 根据用户目标和错误日志排查问题、编写代码及测试；经授权连接服务器操作 |

AI 服务与云 GPU 是两项独立服务：在 AI 服务注册账号并通过其支持的客户端/harness 登录，再单独租用云主机。仅在明确授权后连接指定主机；密码不写入代码、提示词示例或仓库。

## 部署流程

1. 选择能运行 Docker 和 NVIDIA 容器的 GPU **虚拟机**，确认磁盘、CPU、内存与预算，先设定自动关机。普通受限容器可能无法嵌套 Docker；换一个预装 Docker 的容器镜像不一定解决权限限制。
2. 验证 `nvidia-smi`、`docker info` 和 `docker run --rm hello-world`；再用 NVIDIA 官方 CUDA 镜像验证容器内 `nvidia-smi`。按上游版本要求配置 NVIDIA Container Toolkit。
3. 克隆上游训练项目，创建 Python 虚拟环境，安装其 requirements，并运行 `python -m pip check`。配置本地存储后，逐项确认训练镜像、赛道、动作空间和奖励函数。
4. 创建独立模型前缀，备份配置，验证预期 checkpoint 后启动或续训。具体命令以使用的上游版本为准；**不要使用会删除现有模型路径的覆盖参数来解决“路径已存在”**。
5. 用本仓库看板观察奖励和完成率，用仿真摄像头观察车辆行为；只对完整评估圈计算圈速，保留旧模型用于比较。
6. 停训、导出和云主机关机是不同动作。关机前检查 checkpoint 和备份；停止训练并不等于停止云主机计费。

本实践曾使用 Ubuntu 22.04、RTX 3090、Docker 和社区 simapp 6.0.6-gpu。镜像地址、代理和软件版本可能变化，需按当前官方资料验证；公共镜像代理的可达性、白名单和内容完整性不能保证。

## 目录

- `metrics-dashboard/`：Python 读取 S3/MinIO 指标；原生 HTML、JavaScript、SVG 绘制奖励和赛道完成率折线图，每 10 秒刷新。
- `log-sync/`：通过 SSH 只读收集容器日志和指标快照，断线后尽量补拉，凭据只留在内存。
- `custom_files/`：多个奖励函数和动作空间版本；`speed_2018_pace_v3` 是后期实验配置，不保证适合其他赛道。
- `reward_tests/`：奖励边界、转弯速度和动作空间变换测试。离线通过不代表实车或比赛性能达标。
- `docs/`：AI 协作方法与截图清单。

各模块的部署与测试见对应 README。不要把这些配置直接覆盖正在训练的模型；新实验应使用独立前缀。

## 测试

奖励函数测试只使用 Python 标准库：

```bash
python -m unittest discover -s reward_tests -p 'test_*.py' -v
```

看板和日志工具分别安装依赖后，在各自目录运行：

```bash
python -m unittest discover -p 'test_*.py' -v
```

## 安全与结果口径

仓库不包含 SSH/AWS 凭据、真实连接配置、原始日志、模型包或付费教学资料。看板仅监听 loopback，通过 SSH 隧道访问，不直接开放到公网。Docker 控制权通常等同于主机级权限，应只授予可信镜像。

训练回合带有探索噪声；评估完成率、完整圈成功数和完整圈平均圈速应一起比较。仅 `Lap complete` 且完成率为 100% 的记录才计入完整圈圈速；失败回合的短耗时不是更快的成绩。单次最快不代表稳定水平，训练时间增加也不保证稳定性单调提升。

这是 AI 辅助编写、人工提出目标并验证的实验代码。上游 DeepRacer 平台和第三方依赖保持各自的许可证；本仓库没有将它们重新授权。
